# Depeer

## **1️⃣ Lovable.dev Frontend Prompt for Depeer**

> **Project Name:** Depeer
> **Description:**
> Build a responsive, production-ready frontend for **Depeer**, an African SME tokenisation platform. The platform allows investors to buy revenue, asset, and equity tokens, and businesses to issue tokens and track capital. The frontend must integrate seamlessly with a backend API and blockchain smart contracts (TON Blockchain), and support RenexPay payment flows.
>
> **User Roles & Views:**
>
> 1. **Investor Dashboard**:
>
> * Browse tokenised businesses with details: risk score, revenue, assets
>
> * Purchase tokens (revenue/asset/equity)
>
> * Portfolio overview: token holdings, payouts, ROI
>
> * Transaction history
>
> 2. **Business Dashboard**:
>
> * Create verified business profile
>
> * Issue new tokens
>
> * Track revenue & token payouts
>
> * Manage investors & asset backing
>
> * Payment acceptance via RenexPay
>
> 3. **Admin Dashboard**:
>
> * Approve/reject business registrations
> * Audit oversight (financial & blockchain reports)
> * Manage users and compliance data
>
> **Components Required:**
>
> * Login / Registration (with wallet + SBT integration)
> * Multi-role dashboards
> * Token purchase & sale interfaces
> * Revenue/asset visualization (charts, tables)
> * Notifications for payouts & transactions
> * Responsive design (desktop + mobile)
>
> **Tech Requirements:**
>
> * React / Next.js
> * TailwindCSS for styling
> * Connect to backend APIs (Node.js/Express or Python/FastAPI)
> * TON Blockchain integration placeholders
> * RenexPay payment API integration placeholders
>
> **Deliverables:**
>
> * Complete React frontend codebase
> * UI components for Investor, Business, Admin dashboards
> * Navigation, routing, and authentication flows
> * Data visualization components
> * Placeholder integration points for backend, blockchain, and payment API
